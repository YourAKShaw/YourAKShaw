## About me

I'm **Ayush**, a.k.a. **YourAKShaw**, an engineer in **Kolkata, India**. I build REST APIs and microservice templates with **Node.js, NestJS, and Spring Boot**, with a focus on practical architecture and security.

I'm the **Founder & CEO of [YourAKShawInc](https://github.com/YourAKShawInc)**, the parent company behind [CodeinnHQ](https://github.com/CodeinnHQ). My open-source work also includes **AI agent skills**, Python automation, and engineering playbooks. I like turning a useful solution into something another developer can pick up and use.

**Code, coffee, cookies.** And a Linux terminal with some personality.
